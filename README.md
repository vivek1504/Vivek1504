## Projects

### [serverless-runtime](https://github.com/vivek1504/serverless-runtime)
Firecracker microVM-based execution platform built from scratch. Functions run in isolated VMs, cold starts optimized via snapshot restore to ~1ms, throughput benchmarked at ~5K req/sec. Comparable in design to AWS Lambda's execution model.

> `Firecracker` · `Node.js` · `vsock` · `KVM` · `TypeScript`

### [Forge](https://github.com/vivek1504/Forge) · [Live](https://forge.vivekjadhav.xyz)
In-browser IDE powered by WebContainers. Write, run, and preview React, Vue, Svelte, and Node.js projects with zero local setup — Monaco editor, integrated terminal, live HMR preview.

> `WebContainers` · `React` · `Monaco Editor` · `xterm.js` · `TypeScript`

### [Spark](https://github.com/vivek1504/spark) ·  [Live](https://spark.vivekjadhav.xyz)
AI-powered website builder. Natural language prompts → fully functional web apps, running entirely in the browser with live editing and instant previews.

> `TypeScript` · `AI` · `Browser-native`
